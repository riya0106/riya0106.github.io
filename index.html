My Projects

Exploratory Data Analysis of Pharmaceutical Sales

Analyzed six years of daily pharmaceutical sales data (2014–2019) to uncover patterns across eight therapeutic drug categories. Cleaned and preprocessed over 2,000 entries, created time-based aggregations, and visualized category-level, seasonal, and weekday sales trends.

Impact: Revealed key insights such as higher winter sales for respiratory and analgesic drugs, and consistent weekend demand spikes. Demonstrated how EDA can inform inventory planning, staffing, and public health awareness through data-driven insights.

Python Pandas NumPy Matplotlib Seaborn Data Visualization
Documentation Code

Detecting Fraudulent Job Postings Using Classification Models

Built a machine learning model to detect fraudulent job postings using Kaggle's Fake Job Posting dataset. Preprocessed text data, engineered NLP-based features using TF-IDF, and compared classification models including Logistic Regression, Naive Bayes, Random Forest, and XGBoost.

Impact: Identified fraud indicators such as missing company profiles, remote-work claims, vague job locations, and suspicious wording. Demonstrated how classification models can help job platforms flag risky postings and improve trust and safety for job seekers.

Python NLP TF-IDF Scikit-learn XGBoost Classification
Documentation Code

House Price Prediction Using Regression Models

Built regression models to predict house prices using the Ames Housing dataset. Performed data preprocessing, feature selection, missing value handling, scaling, and model comparison using Linear Regression, Ridge Regression, and Lasso Regression.

Impact: Identified key factors influencing home prices, including overall quality, living area, garage size, basement area, and year built. Demonstrated how regression models can support property valuation, pricing decisions, and real estate market analysis.

Python Pandas Scikit-learn Linear Regression Ridge Lasso
Documentation Code

Bank Customer Segmentation Using Clustering

Applied unsupervised machine learning to segment bank customers using the UCI Bank Marketing dataset. Used K-Means and Agglomerative Clustering to identify customer groups based on demographics, financial behavior, and campaign interactions.

Impact: Identified three meaningful customer segments: Established Investors, Mid-Level Professionals, and Young Budget Savers. Demonstrated how clustering can help banks personalize marketing strategies, improve customer targeting, and support data-driven financial product recommendations.

Python Pandas Scikit-learn K-Means Agglomerative Clustering Unsupervised Learning
